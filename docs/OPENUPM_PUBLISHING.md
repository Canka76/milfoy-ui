# OpenUPM Registration & Publishing Guide

## 1. Branch Protection Configuration (GitHub UI)
Before accepting public pull requests:
1. Go to your repository on GitHub → **Settings** → **Branches**.
2. Under **Branch protection rules**, click **Add branch ruleset** or **Add rule** for `main`.
3. Configure the following:
   - **Require status checks before merging**: Enable.
   - Search and select `commitlint` (matches the GitHub Actions job name).
   - **Require branches to be up to date before merging**: Enable.
   - **Do not allow bypassing the above settings**: Enable (enforces rules on maintainers as well).
4. Save changes.

## 2. Pushing to GitHub
```bash
git remote add origin https://github.com/<yourgithuborg>/ui-depth-inspector.git
git push -u origin main
```

## 3. OpenUPM Registration (One-time PR)
1. Fork [https://github.com/openupm/openupm](https://github.com/openupm/openupm).
2. Create a new file in your fork: `data/packages/com.openupm.ui-depth-inspector.yml`:
```yaml
name: com.openupm.ui-depth-inspector
displayName: UI Layer & 3D Depth Inspector
description: Interactive 3D exploded viewport for debugging uGUI Canvas draw order, raycast blockers, and mask boundaries directly inside the Unity Editor.
repoUrl: https://github.com/<yourgithuborg>/ui-depth-inspector
licenseSpdxId: MIT
topics:
  - ui
  - ugui
  - canvas
  - debug
  - editor
  - depth
hunter: <your-github-username>
```
3. Open a Pull Request to `openupm/openupm`.
4. Once merged, OpenUPM will automatically track and mirror all GitHub release tags generated by `release-please`.
